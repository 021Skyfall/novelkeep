## 핵심 사용자

- **독자:** 미완결 위험 없이 웹소설을 실물로 소장하려는 20~30대
- **작가:** 충성 독자는 있으나 직접 출판·재고가 어려운 독립 작가
- **운영:** 펀딩 결과와 제작 주문을 처리하는 관리자

## 작가 페르소나 5명

### W1. 김하린 — 퇴근 후 연재하는 신인
29세 직장인 · 로맨스 판타지 · PC 집필 / 모바일 현황  
첫 장편이라 완결 의지가 흔들린다.

- **목표:** 소장본 수요를 보며 첫 부를 완결
- **불편:** 조회 수만으로 구매 의사를 알기 어려움
- **필요:** 부 진행, 펀딩 인원·달성률, 출판 조건 안내

### W2. 박도윤 — 소규모 팬덤 독립 작가
34세 프리랜서 · 이전 작품 독자 ~300명 · PC 중심  
선입금·인쇄·배송을 직접 해본 경험이 있다.

- **목표:** 재고·배송 없이 팬에게 소장본
- **불편:** 연재 플랫폼과 인쇄·주문이 분리됨
- **필요:** 펀딩 개설, 분량 안내, 주문 전환·제작 상태 조회

### W3. 이수민 — 부 단위 장기 작가
31세 전업 · 1부·2부로 나눠 연재 · PC / 모바일  
전체 완결까지 기다리면 소장본이 너무 늦다.

- **목표:** 부 완결마다 소장본 제공
- **불편:** 전체 완결과 부 완결을 구분하지 않음
- **필요:** 연재 중·부 완결·전체 완결 구분, 부별 구성

### W4. 최우진 — 완결작 재출판
37세 · 과거 완결 판타지 보유 · 종이책 경험 없음 · PC

- **목표:** 재고 부담 없이 현재 수요 검증
- **불편:** 최소 제작 수량을 먼저 떠안는 부담
- **필요:** 완결작 등록, 목표 수량, 실패 시 환불 상태

### W5. 정서윤 — 필명 민감 작가
26세 취미 · 필명만 활동 · 모바일 반응 / PC 집필

- **목표:** 개인 배송 없이 필명으로 소장본
- **불편:** 제작·결제·배송 문의를 혼자 감당
- **필요:** 필명 중심 표시, 펀딩·제작 상태의 명확한 안내

## 독자 페르소나 6명

### R1. 윤지아 — 결제에 신중한 독자
28세 · 연재 중단 결제 경험 · 출퇴근 모바일

- **목표:** 응원하되 미완결이면 안전하게 환불
- **불편:** 연재·출판 조건이 잘 안 보임
- **필요:** 완결 표시, 기한, 실패·환불 조건

### R2. 강민호 — 소장형 독자
32세 · 단행본·굿즈 수집 · 모바일 열람 / PC 상세

- **목표:** 만족한 작품을 실물로 소장
- **불편:** 소장본 여부를 SNS에서 찾아야 함
- **필요:** 포함 회차·수량, 제작 진행 상태

### R3. 오세진 — 예산형 독자
25세 취준 · 월 취미 예산 고정 · 모바일

- **목표:** 추가 비용·장기 미배송 없이 참여
- **불편:** 미달·실패 시 처리가 불명확하면 결제 안 함
- **필요:** 금액·목표·기간·환불의 쉬운 문구

### R4. 한예린 — 완결 후 몰아보기
30세 · 부 완결 후 한꺼번에 읽음 · 태블릿·모바일

- **목표:** 완결작을 빠르게 찾고 읽은 뒤 주문
- **불편:** 연재·완결이 섞여 탐색이 김
- **필요:** 완결 필터, 회차 이동, 읽기 편한 본문

### R5. 임태경 — 초기 후원 독자
27세 · 신인 작품 발굴·추천 · 모바일로 진행률 확인

- **목표:** 참여가 완결·출판에 기여하는 느낌
- **불편:** 참여 후 진행이 안 보이면 불안
- **필요:** 참여 수·달성률·완결 조건·주문 전환

### R6. 서나래 — 독자→예비 작가
27세 · 출퇴근 독서 / 퇴근 후 원고 · 모바일 탐색 / PC 작성

- **목표:** 독자 화면을 유지한 채 작가 기능으로 첫 미공개 작품
- **불편:** 독자·작가 서비스가 분리되거나 계정을 다시 만들면 부담
- **필요:** 작가 권한 활성화 진입, 누적 메뉴, 첫 작품 안내
- **데모:** 전환 시 고정 회원이 바뀌어 즐겨찾기 등이 이어지지 않음 (실서비스는 동일 회원 승격)

## 관리자 페르소나

### A1. 이지훈 — 운영자
35세 · PC 중심 · 성공 펀딩→주문 전환을 매일 확인

- **목표:** 현황 파악과 제작 지연 없는 상태 처리
- **불편:** 작품·펀딩·주문이 흩어지면 누락을 찾기 어려움
- **필요:** 통계, 주문 검색·필터, 순차 상태 변경, CSV/JSON

## 공통 UX 판단

- 독자: 모바일 우선 · 쉬운 상태 문구 / 작가·운영: PC 우선
- 탐색이 본체 → **같은 공개 콘텐츠**, 역할별로는 **관리 메뉴만** 추가
- 연재 상태와 공개 여부 분리. 미공개는 소유자·운영자만. 운영자도 타 작품 수정 불가
- 역할별 고정 체험 회원 1명 + 세션. 작가는 독자 기능을 포함. 운영자 메뉴는 대시보드·펀딩·주문만(독자·작가 메뉴 미누적, 공개 URL 열람 허용)
- 독자→작가 체험만. 전환 시 계정이 바뀌어 즐겨찾기·추천은 이어지지 않음
- 부 완결은 `1부 완결`처럼 번호 표시. 출판은 부 완결+목표(분량은 안내)
- 모의 결제·성공/실패/환불/주문 상태를 분명히 구분
- 과제 범위 밖: 인증·실결제·정산·배송·서버 푸시. 댓글·토스트는 Lv1 포함

## MVP 우선순위

1. 독자 목록·상세·회차 열람  
2. 작가 작품·회차 생성·수정·완결  
3. 독자 펀딩 참여(모의 결제)  
4. 완결·목표 판정과 주문 전환  
5. 운영자 주문 상태·통계  
6. CSV·JSON 내보내기

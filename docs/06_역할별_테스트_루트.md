# 역할별 화면 동선 테스트 (Lv1 + Lv2 펀딩·주문)

> 브라우저에서 클릭하며 확인하는 가이드다.  
> 시작: `http://localhost:8080` → `docker compose up --build` 후 접속  
> 앱을 재시작하면 목 데이터가 초기화된다. ID는 화면에서 보이는 것을 그대로 따라가면 된다.

---

## 시작 전 공통

1. 브라우저로 랜딩(`/`)을 연다.
2. **독자로 체험 / 작가로 체험 / 운영자로 체험** 중 하나를 고른다.
   - 독자·작가 → `/main`
   - 운영자 → `/admin/orders`
3. 역할을 바꿀 때는 우상단 **역할 변경** → 랜딩에서 다시 고른다.
4. 독자의 **작가가 되고 싶으신가요?** 는 안내 팝업만 띄운다. 실제 작가 테스트는 **역할 변경** 후 랜딩에서 작가를 고른다.

### 상단 탭 · 내비

- **홈(`/main`)에서만** 상단 탭(홈·인기작·신작·완결작·소장본 펀딩)이 보인다. 탭을 누르면 해당 벨트 위치로 스크롤된다.
- 다른 화면에서는 역할 메뉴만 보인다. 상단바+역할 메뉴는 sticky.
- 우하단 플로팅: **위로가기** → **홈** 아이콘 순.

---

## 1. 독자 — 한 바퀴 동선

### ① 메인에서 둘러보기

1. 랜딩에서 **독자로 체험**을 고른다. (`독자 체험 중` 배지)
2. **인기작** 벨트에서 카드를 **클릭** → 작품 상세로 간다.
3. 뒤로 온 뒤 **새 회차** 벨트 카드를 클릭 → 회차 본문이 열린다.
4. 다시 메인으로 와 **완결작(몰아보기)** 카드: 커버에 장르가 없고, 본문 메타+장르·하단 게이지를 본다.
5. **소장본 펀딩** 카드를 클릭 → 펀딩 상세. **결제하고 참여하기**(확인 팝업). 상태 배지 **펀딩 중**. 시드 참여 건은 `이미 참여했습니다`.
6. 참여 후 부수·달성률이 오르고 재참여가 막히는지 본다. 히어로·하단 벨트 **가로 드래그·자동 슬라이드·끝에서 첫 카드 이어짐**도 확인한다.
7. 인기 카드: 메타와 장르가 분리되고, 장르 줄 끝 **`...`** → 펼침/`접기`. 커버 추천 옆에 펀딩 **뱃지**(게이지 없음).

### ② 작품 탐색 · 태그 · 추천 · 즐겨찾기

1. 역할 메뉴 **작품 탐색**으로 목록을 연다. (공개 작품만)
2. 검색창에 글자만 치고 **아직 검색되지 않음**을 확인한다.
3. **돋보기** 또는 **Enter** → 그때 검색된다.
4. 장르·연재 상태·**펀딩 중 전체/Y/N**·정렬을 바꿔 목록이 바로 갱신되는지 본다.
5. 장르가 많은 카드에서 장르 줄 **맨 끝 `...`** → 펼침/`접기`(메타 줄과 분리).
6. 카드 **빈 곳**을 누르면 상세로 가고, **즐겨찾기(우상단) / 추천+따봉(우하단)** 만 누르면 토글만 된다.
7. 커버에 상태·부완결(좌상단), OPEN **게이지는 추천 왼쪽**에 있는지 본다.
8. 즐겨찾기한 뒤 메뉴 **내 즐겨찾기** → 그 작품만 보이는지 확인한다.

### ③ 읽기 · 책갈피 · 댓글 · 미공개 권(부)

1. 작품 상세에서 회차 목록을 본다.  
   - **최신 화가 위**  
   - 제목 옆에 **`(댓글 수)`**  
   - **미공개 권(부)는 독자에게 섹션 자체가 안 보인다.**
2. 태그: 상태/공개/부완결/추천 → 다음 줄에 장르. **`N권` 태그는 없다.**
3. OPEN 중인 부에 **펀딩 참여하기**(또는 `참여 완료 · 현황`)가 보이는지 확인한다.
4. 한 화를 연다. 본문 **양옆**의 ‹ › 로 이전/다음 화 이동.
5. 메뉴 **내 책갈피** → 이어 읽기·해제를 해 본다.
6. 회차 맨 아래 **댓글**에서 작성·답글·수정·삭제를 확인한다.

### ④ 내 펀딩·주문

1. 메뉴 **내 펀딩·주문** → `/reader/activities`.
2. 탭 **전체 / 참여 중 / 주문 / 환불**이 모두 표(테이블)로 보이는지 확인한다.
3. **참여 중**: 시드 참여·승인 대기, 상태 **펀딩 중**/성공·실패, **상세 내역**·펀딩 상세.
4. **주문**: 시드 주문(상태 분산) + 출판 상태 칩 필터.
5. **환불**: 시드 환불 완료 건. (OPEN 중 환불은 **펀딩 상세**의 환불하기)
6. 상단 안내: 환불은 해당 작품 펀딩 상세에서 가능하다는 문구.
7. 작품명 검색·정렬·초기화가 AJAX로 동작하는지 본다.

> 시드: 체험 독자 — 참여 중·주문·환불 + 참여 가능 OPEN. 탐색 1–2위는 목표 달성 OPEN(참여만 하면 마감→승인→주문 흐름 확인용). 게이지·다인 참여는 mock 독자로 채움.

### ⑤ 막혀야 하는 것

1. 주소창에 작가 전용 화면을 직접 치면 → 랜딩/안내로 막힌다.
2. 남의 미공개 작품·미공개 권 회차 URL → 404.

### 독자 한눈에

```text
랜딩 → 독자
→ 메인 (벨트·장르 ... ·펀딩 뱃지)
→ 소장본 펀딩 상세 (결제하고 참여하기 · 펀딩 중)
→ 내 펀딩·주문 (전체/참여 중/주문/환불)
→ 작품 탐색 (상단 1–2 성공준비 OPEN · 펀딩 중 Y/N·장르 ...)
→ 작품 상세 · 회차 · 책갈피 · 댓글
→ 역할 변경
```

## 2. 작가 — 한 바퀴 동선

작가는 독자 메뉴도 같이 쓴다.

### ① 내 작품

1. **내 작품**에서 소유 작품만 본다. **펀딩 중 Y/N** 필터가 동작하는지 확인한다.
2. 카드: 태그(메타) → 제목 → 필명 → **하단 펀딩 게이지**. 장르 줄 `...` 클릭(제목만 상세 이동).

### ② 부 · 회차 다루기 (작품 상세)

1. 작품 상세 **회차 구성**에서 권 추가·수정·삭제, 회차 `+ 작성`·일괄 공개/미공개/삭제를 확인한다.
2. 완결 부에서 회차만 미공개로 바꿔도 **부 상태는 완결 유지**.

### ③ 공개 / 미공개

1. 작품 미공개 → 내 작품에는 있고 탐색에는 없다.
2. 권 미공개 → 작가 상세에는 있고 독자에서는 섹션 없음.

### ④ 출판 펀딩 (OPEN·마감·승인 대기)

1. 공개 작품·공개 회차 부에서 **출판 펀딩 시작** → 목표 부수(≥10)·판매가·기간.
2. 메뉴 **내 펀딩 관리** → OPEN/SUCCESS/FAILED가 보이고, **펀딩 상태·출판 상태** 칩 필터가 동작한다.
3. 수요 0 → **취소** 가능. 수요 1 이상 → 취소 불가.
4. **마감** → SUCCESS 또는 FAILED. 카드는 남고 **승인 대기**. 주문/환불은 아직 없음.
5. 역할 변경 → 운영자에서 승인 후 다시 작가로: SUCCESS면 `주문이 접수되었습니다. 현재 {상태} 단계입니다.`
6. OPEN 중 부·회차 수정·삭제·미공개·작성이 막히는지 확인. **댓글**은 가능.

### ⑤ 아직 준비 중

- (없음 — 작가 주문 조회는 내 펀딩 관리에 포함)

### 작가 한눈에

```text
랜딩 → 작가
→ 내 작품 (펀딩 중 필터·하단 게이지·장르 ...)
→ 작품 상세 (권·회차·펀딩 시작)
→ 내 펀딩 관리 (마감·필터·승인/출판 상태)
→ 역할 변경
```

## 3. 운영자 — 한 바퀴 동선

운영자는 **주문 관리·펀딩 관리**만 사용한다.

### ① 진입

1. 랜딩에서 **운영자로 체험** → `/admin/orders`.
2. 상단에 **주문 관리**·**펀딩 관리**가 보인다.
3. `/novels`, `/main` 등으로 직접 이동하면 다시 주문 쪽으로 돌아온다.

### ② 펀딩 관리 (`/admin/fundings`)

1. 승인 대기 SUCCESS/FAILED가 보이는지 확인한다.
2. **승인** → SUCCESS는 주문 접수, FAILED는 모의 환불.
3. **거절** → 캠페인이 OPEN으로 돌아가는지 확인한다.

### ③ 주문 관리 (`/admin/orders`)

1. **캠페인(작품) 묶음** 목록(수량 합·참여 건수·제품 상태)을 확인한다.
2. 작품명·상태·주문일로 **필터**한다.
3. **주문 상세**에서 결제자별 내역·**상세 내역(영수증)** 팝업을 확인한다.
4. 묶음 단위로 접수 → 제작중 → … → 배송완료 **상태 변경**한다.
5. 현재 필터로 **CSV / JSON** 다운로드(한글 깨짐 없이).

### 운영자 한눈에

```text
랜딩 → 운영자
→ /admin/fundings (승인·거절)
→ /admin/orders (캠페인 묶음·상세·영수증·6단계·CSV/JSON)
→ 역할 변경
```

## 4. 역할 바꿀 때

| 할 일 | 결과 |
|---|---|
| 독자 → **작가가 되고 싶으신가요?** | 안내 팝업만. **역할 변경** 누르면 랜딩으로 이동 |
| 작가/운영자 → 독자 | **역할 변경** 후 랜딩에서 독자 다시 선택 |
| 데이터 이어보기 테스트 | 같은 역할로 끝까지 진행 |

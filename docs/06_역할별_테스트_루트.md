# 역할별 화면 동선 테스트 (Lv1)

> 브라우저에서 클릭하며 확인하는 가이드다.  
> 시작: `http://localhost:8080` → `docker compose up --build` 후 접속  
> 앱을 재시작하면 목 데이터가 초기화된다. ID는 화면에서 보이는 것을 그대로 따라가면 된다.

---

## 시작 전 공통

1. 브라우저로 랜딩(`/`)을 연다.
2. **독자로 체험 / 작가로 체험 / 운영자로 체험** 중 하나를 고른다.
   - 독자·작가 → `/main`
   - 운영자 → `/admin/orders`
3. 역할을 바꿀 때는 우상단 **역할 변경** → 랜딩에서 다시 고른다.
4. 독자의 **작가가 되고 싶으신가요?** 는 안내 팝업만 띄운다. 실제 작가 테스트는 **역할 변경** 후 랜딩에서 작가를 고른다.

### 상단 탭 (역할 공통)

홈 → 인기작 → 신작 → 완결작 → 소장본 펀딩  
각 탭을 누르면 메인에서 해당 벨트 위치로 스크롤된다.

---

## 1. 독자 — 한 바퀴 동선

독자 범위는 정리된 상태다. 아래 순서대로 보면 된다.

### ① 메인에서 둘러보기

1. 랜딩에서 **독자로 체험**을 고른다. (`독자 체험 중` 배지)
2. **인기작** 벨트에서 카드를 **클릭** → 작품 상세로 간다.
3. 뒤로 온 뒤 **새 회차** 벨트 카드를 클릭 → 회차 본문이 열린다.
4. 다시 메인으로 와 **완결작** 카드를 클릭 → 완결 작품 상세.
5. **소장본 펀딩** 카드를 클릭 → 펀딩 현황. 참여 버튼은 `준비 중`.
6. 벨트에서 카드를 **가로로 드래그**해 본다. URL이 잡히거나 드래그가 끊기지 않아야 한다.
7. 상단 탭(인기작~펀딩)을 눌러 각 섹션으로 스크롤되는지 본다.

### ② 작품 탐색 · 태그 · 추천 · 즐겨찾기

1. 역할 메뉴 **작품 탐색**으로 목록을 연다. (공개 작품만)
2. 검색창에 글자만 치고 **아직 검색되지 않음**을 확인한다.
3. **돋보기** 또는 **Enter** → 그때 검색된다.
4. 장르 배지·연재 상태·정렬을 바꿔 보면 목록이 바로 갱신된다.
5. 장르가 많은 카드에서 태그 줄 아래 **`...`** 이 보이면 눌러 **펼침 / 접기**를 확인한다.  
   (목 데이터는 작품마다 장르 2~8개. 긴 이름 7~8개인 카드에서 `...`이 잘 나온다.)
6. 카드 **빈 곳**을 누르면 상세로 가고, **★ / 추천**만 누르면 상세로 가지 않고 토글만 된다.
7. 필명은 카드 **맨 아래**에 붙어 있고, 태그 수와 관계없이 위치가 일정해야 한다.
8. 즐겨찾기한 뒤 메뉴 **내 즐겨찾기** → 그 작품만 보이는지 확인한다.

### ③ 읽기 · 책갈피 · 댓글 · 미공개 권(부)

1. 작품 상세에서 회차 목록을 본다.  
   - **최신 화가 위**  
   - 제목 옆에 **`(댓글 수)`**  
   - **미공개 권(부)는 독자에게 섹션 자체가 안 보인다.** (목 연재작의 집필 중 부 등)
2. 한 화를 연다. 본문 **양옆**의 ‹ › 로 이전/다음 화 이동(스크롤해도 고정). 호버 시 안내 문구.
3. 좌상단 **←** = 작품 상세, 우상단 **책갈피 아이콘**(호버 시 저장/해제 문구). 알림은 왼쪽 아래.
4. 본문을 스크롤해 우측 **맨 위로** 버튼이 보이는지 확인한다.
5. 메뉴 **내 책갈피** → 이어 읽기·해제를 해 본다.
6. 회차 맨 아래 **댓글**에서:
   - 댓글 작성 → 목록에 보인다.
   - **답글** → `└` 아래로 한 단만. (답글에는 답글 버튼 없음)
   - 본인 댓글 **수정** → 내용이 바뀐다.
   - 답글이 달린 부모를 **삭제** → 부모만 `삭제된 댓글입니다.`, 답글은 남는다.
   - 답글만 **삭제** → 목록에서 바로 사라진다.

### ④ 막혀야 하는 것

1. 주소창에 작가 전용 화면(예: 작품 등록)을 직접 치면 → 랜딩/안내로 막힌다.
2. 남의 미공개 작품 주소를 추정해 열면 → 안 보인다(404).
3. 미공개 권(부) 안의 회차 URL을 추정해 열면 → 안 보인다(404).
4. **내 펀딩·주문** 메뉴는 `준비 중`.

### 독자 한눈에

```text
랜딩 → 독자
→ 메인 (벨트 클릭·드래그·상단 탭)
→ 작품 탐색 (검색·장르·... 태그·★·추천)
→ 작품 상세 (최신화 위, 댓글 수, 미공개 부 미노출)
→ 회차 읽기 (책갈피·댓글·답글)
→ 내 책갈피 / 내 즐겨찾기
→ 역할 변경
```

## 2. 작가 — 한 바퀴 동선

작가 Lv1(작품·부·회차 관리)은 정리된 상태다. 작가는 독자 메뉴도 같이 쓴다.

### ① 내 작품 만들기 · 고치기

1. 랜딩에서 **작가로 체험** (`작가 체험 중`, **내 작품** 메뉴)
2. **내 작품** → 본인 작품만 보인다.
3. **작품 등록** → 제목·필명·소개·장르(1~8)·연재 상태·공개 여부를 넣고 저장한다.
4. 상세에 기본 부 **본편**이 하나 있는지 본다.
5. **기본 정보 수정**(상세 우측)으로 내용을 바꾼 뒤 상세로 돌아온다.
6. (맨 마지막에) **작품 영구 삭제** → 되돌릴 수 없다는 안내 후 목록으로.

### ② 부 · 회차 다루기 (작품 상세에서)

1. 작품 상세 **회차 구성**에서 관리한다. (`전체 관리하기` 버튼은 쓰지 않는다.)
2. 우측 **+ 권(부) 추가** → 제목·상태(미공개/연재 중)를 넣고 저장(AJAX, 목록만 갱신).
3. 권이 2개 이상이면 부 제목 옆 **수정 / 삭제**로 제목·상태를 바꾼다.
4. 회차 목록 맨 위 **+ 작성** → 회차 작성 전용 화면 → 저장 후 상세 복귀.
5. 회차 행 **수정** / **삭제**, 읽기 화면에서도 소유자 **수정·삭제**.
6. 체크박스로 여러 회차 선택 → **공개 / 미공개 / 삭제** (각각 확인 팝업 후 AJAX).  
   - 완결 부에서 회차만 미공개로 바꿔도 **부 상태는 완결로 유지**되는지 확인.
7. 회차·부 삭제 후 번호가 다시 맞춰지는지 본다.

### ③ 공개 / 미공개

1. 작품을 **미공개**로 두면 → **내 작품**에는 있고 **작품 탐색**에는 없다.
2. 특정 **권(부)를 미공개**로 두면 → 작가 상세에는 보이지만, 역할 변경 후 **독자**로 보면 그 권 섹션이 없다.
3. **공개** 작품 + **연재 중/완결** 권 + **공개** 회차로 바꾼 뒤, 독자로 열람이 되는지 본다.

### ④ 아직 준비 중

- 출판·펀딩 관리 → `준비 중`
- 내 펀딩·주문 → `준비 중`

### 작가 한눈에

```text
랜딩 → 작가
→ 내 작품 → 등록·수정·삭제
→ 작품 상세 (+권, 부 수정/삭제, +작성, 일괄 공개·미공개·삭제)
→ 회차 읽기에서 수정·삭제
→ 독자로 미공개 권 미노출 확인
→ 역할 변경
```

## 3. 운영자 — 한 바퀴 동선

운영자는 **주문 대시보드만** 사용한다. 작품 탐색·작가 메뉴에는 들어가지 않는다.

### ① 진입

1. 랜딩에서 **운영자로 체험** → `/admin/orders`로 바로 이동한다.
2. 상단에는 **전체 주문 관리**만 보인다.
3. `/novels`, `/main` 등으로 직접 이동하면 다시 주문 대시보드로 돌아온다.

### ② 주문 대시보드

1. 시드 주문 목록이 보이는지 확인한다.
2. 작품명·상태·주문일로 **필터**한다.
3. 접수 → 제작 중 → 제작 완료 순으로 **상태 변경**한다.
4. 현재 필터 기준으로 **CSV / JSON 다운로드**한다. (CSV는 한글 깨짐 없이)

### 운영자 한눈에

```text
랜딩 → 운영자
→ /admin/orders
→ 필터 · 상태 변경 · CSV/JSON
→ 역할 변경
```

---

## 4. 역할 바꿀 때

| 할 일 | 결과 |
|---|---|
| 독자 → **작가가 되고 싶으신가요?** | 안내 팝업만. **역할 변경** 누르면 랜딩으로 이동 |
| 작가/운영자 → 독자 | **역할 변경** 후 랜딩에서 독자 다시 선택 |
| 데이터 이어보기 테스트 | 같은 역할로 끝까지 진행 |

---

## 5. 나중에 (Lv2)

- 독자: 펀딩 상세에서 참여(모의 결제) → 내 펀딩·주문
- 작가: 출판·펀딩 관리 → 마감·주문 현황
- 운영자: 실제 펀딩 성공 전환 주문과 대시보드 연동 강화

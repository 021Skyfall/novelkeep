# 역할별 테스트 루트

`docker compose up --build` → `http://localhost:8080`

앱 재시작 시 시드가 초기화되고 **세션(체험 역할)도 사라진다**.  
AJAX 목록을 연 채로 재시작하면 랜딩(역할 선택)으로 돌아가야 정상이다.  
역할은 **역할 변경**으로만 바꾼다.  
독자→작가 체험은 고정 회원이 바뀌므로 즐겨찾기·추천이 이어지지 않는다.

검증 체크리스트. `[ ]` → `[x]`

## 0. 공통

- [x] 랜딩에서 독자 / 작가 / 운영자 선택 가능
- [x] 독자·작가 → `/main` , 운영자 → `/admin`(대시보드)
- [x] **역할 변경** → 랜딩 복귀
- [x] 독자 **작가가 되고 싶으신가요?** → 안내만 (실제 전환 X, 랜딩에서 작가 선택)
- [x] 최초 방문(또는 테마 미저장) → **다크 모드** 기본. 토글 후 `localStorage`에 유지
- [x] 상단 내비·플로팅·다크/라이트 토글이 랜딩 외 화면에 공통 적용
- [x] 「상세」「초기화」 버튼이 흐린 secondary가 아니라 outline-dark로 잘 보임
- [x] 서버 재시작 직후 AJAX 검색·필터 → 목록에 랜딩이 끼지 않고 역할 선택으로 이동

## 1. 독자 (약 12분)

### 메인·탐색
- [x] 인기 / 신작 / 완결 / 소장본 펀딩 벨트: 클릭 이동·가로 드래그·앵커 탭
- [x] 펀딩 상세 → **결제하고 참여하기** (또는 `이미 참여했습니다`) · 배지 **펀딩 중** · 게이지 갱신
- [x] 작품 탐색: 돋보기/Enter 검색, 장르·펀딩 중 Y/N, 장르 `...` 펼침, **초기화**
- [x] 탐색 **맨 앞 1·2번째** = 게이지가 거의 찬 OPEN (참여·마감 흐름을 짧게 확인)
- [x] 추천·즐겨찾기 토글 → **내 즐겨찾기**에 반영 (스크롤 유지 AJAX)

### 읽기
- [x] 작품 상세: 미공개 권 안 보임, OPEN 부면 **펀딩 참여하기** / 참여 완료·상세
- [x] 회차 읽기: 이전화·다음화(뷰포트 중앙 고정), **작품 상세·책갈피**(상단 좌·우 고정)
- [x] 책갈피 저장·해제 → **내 책갈피**에서 이어읽기
- [x] 댓글 작성·답글(1단)·본인 수정·소프트 삭제

### 내 펀딩·주문 `/reader/activities`
- [x] 탭 **전체 / 참여 중 / 주문 / 환불** (모두 표)
- [x] 필터·정렬·**초기화**, **상세 내역**(영수증) 팝업, **상세**(펀딩)
- [x] OPEN 건 → 펀딩 상세 **환불하기** → **같은 펀딩 상세에 잔류**·게이지/버튼 갱신
- [x] 내 펀딩에서 펀딩 상세 진입 후 **← 내 펀딩 관리** 등으로 이전 화면 복귀

### 막힘 확인
- [x] 작가 URL 직접 접근 → 막힘(랜딩·권한 안내)
- [x] 미공개 회차 URL → 404

```text
랜딩→독자→메인→펀딩 참여→탐색→회차(스티키)·댓글→내 펀딩·주문→환불→역할 변경
```

## 2. 작가 (약 12분)

- [x] **내 작품**: 내 것만, 펀딩 중 Y/N, 하단 게이지, 검색·**초기화**
- [x] 작품 상세: 권·회차 추가/수정/삭제, `+ 작성`, 부별·회차 일괄 **공개·비공개·삭제**
- [x] 회차만 비공개해도 **부 완결 유지**
- [x] 작품/권 비공개 → 탐색·독자에게 안 보임
- [x] **출판 펀딩 시작**(목표 ≥10) → **내 펀딩 관리** / 상세의 **펀딩 수정·펀딩 관리**
- [x] 수요 0만 취소 / 수요 있으면 취소 불가
- [x] **OPEN 중**: 부·회차 **작성·수정·공개/비공개 가능**, **삭제(단건·일괄·부)만 불가**
- [x] **마감**
  - 목표 미달 또는 부 미완결 → FAILED · 승인 대기
  - 목표 달성 + 성공 톤 확인창. **전체 회차 공개·부 완결** 미충족 시 「예, 마감」비활성·「아니오」강조
  - 조건 충족 마감 → SUCCESS · 승인 대기
- [x] 내 펀딩 관리: 작품 제목·표지 → 작품 상세, **펀딩 상세** 링크, 출판 상태 문구
- [x] 운영자 승인 후 다시 작가: 주문/환불·출판 단계 안내 확인

```text
랜딩→작가→내 작품→상세(펀딩 시작·OPEN 중 수정/삭제차단)→내 펀딩 관리(마감)→역할 변경
```

## 3. 운영자 (약 10분)

### 대시보드 `/admin`
- [x] 첫 화면이 대시보드
- [x] 숫자·펀딩 현황·제품 주문별 상태·최근 묶음 표시
- [x] CSV / JSON 다운로드
- [x] 운영자 메뉴는 대시보드·주문·펀딩만. `/novels` 등 공개 경로도 **직접 URL로 열람 가능**(강제 `/admin` 리다이렉트 없음)

### 펀딩 관리 `/admin/fundings`
- [x] 승인 대기 목록, 작품명·**일자 범위(flatpickr)**·승인/상태 칩, **초기화**
- [x] **승인**: 성공→주문 접수 / 실패→모의 환불
- [x] **거절** → OPEN 복귀
- [x] **펀딩 상세** 링크, CSV / JSON (필터 반영)

### 주문 관리 `/admin/orders`
- [x] 작품(펀딩) **묶음** 목록, 필터·일자·**초기화**
- [x] **상세** / **주문 상세** · 영수증 팝업
- [x] 상태 진전: 접수→…→배송완료
- [x] CSV / JSON (필터 반영, 한글 깨짐 없음)

```text
랜딩→운영자→대시보드→펀딩 승인→주문 상태 변경·CSV→역할 변경
```

## 4. 한 줄 핵심 시나리오

1. **독자**: 탐색 1위 작품 → 참여 → 내 펀딩·주문
2. **작가**: (필요 시) 회차 공개·부 완결 맞춘 뒤 마감 → 승인 대기
3. **운영자**: 승인 → 주문 관리에서 상태 변경·CSV
4. **독자**: 주문 탭에서 제품 상태 확인

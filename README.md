# 노벨킵 (NovelKeep)

스위트북 개발 과제로 제작하는 완결 조건부 웹소설 소장본 펀딩 서비스입니다.

## 현재 상태

Phase 0 기획 단계입니다. 서비스 주제, 타겟 사용자와 기술 스택을 확정했습니다.

## 서비스 소개

연재 웹소설을 읽고, 부 완결 또는 전체 완결과 펀딩 목표 달성 후 종이책으로 소장할 수 있는 서비스입니다.

- 주요 타겟: 미완결 위험 없이 좋아하는 웹소설을 실물로 소장하려는 20~30대 독자
- 작가가 부 구분 사용 여부를 선택해 회차를 연재하고 독자가 온라인으로 열람
- 출판 회차 범위와 권당 목표 글자 수로 한 권 예상 분량을 확인
- 독자가 소장본 펀딩에 참여하면 결제를 모의 처리하고 참여 수를 집계
- 완결 조건과 목표 수량을 충족하면 책 제작 주문으로 전환
- 조건 미충족 시 환불 상태로 전환
- 랜딩페이지에서 독자·작가·관리자 체험 역할 선택
- 관리자의 운영 통계, 전체 주문 상태 관리와 CSV·JSON 내보내기
- 사업 관점: 스위트북 Book Print API를 도입할 B2B 파트너형 콘텐츠 플랫폼을 독립 실행형으로 구현

## 과제 범위

- 웹소설 작품·회차 생성, 조회, 수정과 열람
- 펀딩 참여, 모의 결제·환불과 목표 달성 상태 관리
- 부 완결 또는 전체 완결 작품의 책 주문 생성·조회와 관리자 제작 상태 관리
- 로그인 없이 시드 작가·독자·관리자와 세션으로 체험 역할 및 데이터 소유권 구분
- 관리자 통계와 주문 CSV·JSON 내보내기
- 실제 인쇄 API, PG 결제, 배송과 회원 인증은 구현하지 않음
- 외부 서비스에 의존하지 않고 Docker로 실행
- 웹툰·기존 플랫폼(문피아 등) 연동은 구현하지 않음 (확장안)

## 기술 스택

- Java 21, Spring Boot 4.1.0
- Maven 3.9.16, Spring Data JPA, MariaDB
- Thymeleaf, JavaScript, Bootstrap 5.3.8, HTML/CSS
- Docker Compose

## 실행 방법

프로젝트 구성 확정 후 작성합니다.
